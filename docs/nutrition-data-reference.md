# 营养控制区初始清单

首次安装的营养控制区含以下五个转盘选项，按从十二点方向顺时针排列：

| 顺序 | 名称 | 基础身份 |
|---|---|---|
| 1 | 赛百味 | nutrition-01 |
| 2 | 沙县鸡腿饭 | nutrition-02 |
| 3 | 潮汕牛肉汤饭 | nutrition-03 |
| 4 | 蛋白粉+农耕记米饭 | nutrition-04 |
| 5 | 霸碗盖码饭 | nutrition-05 |

它们是 `scene=takeout / zone=nutrition` 下的独立分组。名称中的换行由界面排版决定，不写入数据。分组下没有预置餐品、备注或次数，可由使用者自行添加；这些名称不代表营养计算或健康评级。

## 初始化与兼容性

- `app/src/main/assets/seed.json` 保留这五组以及原有 61 条餐品。六条做饭食材由 Repository 单独初始化。
- 五餐各有自己的初始化标记。已有标记时跳过预置，不重复添加、不覆盖自定义名称、不恢复已删除记录。
- Room 4 按餐次隔离分组；晚餐保留基础身份，其他餐次使用稳定前缀，见 [五餐独立数据规则](meal-isolation.md)。
- 普通界面评估应覆盖有数据的转盘；空盘和单项盘另外作为边界场景。测试新增预置时使用独立调试数据，不清空使用者的真实数据库。

初始清单中的商家名称和个人口味备注均可编辑。仓库不包含原始私人手机截图或设备消费记录。

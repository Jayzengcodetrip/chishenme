# 吃什么 · 设计系统 MASTER（1.4.2 · Things 风格）

按 UI UX Pro Max 的 Master + Overrides 结构整理。改任何页面前先读本文件；页面专属规则放在 `pages/<页面>.md`，与本文件冲突时以页面文件为准。

## 来源与决策
- 风格：用户在设计稿中选定「参照 Things 3」方向（Things 获 2017 Apple Design Award）。
- UI UX Pro Max `--design-system`（查询 "meal decision food picker app minimal productivity"，variance 3 / motion 3 / density 5）给出 **Minimalism & Swiss Style**、赤陶主色、单一 CTA。与所选方向一致的部分采用；它推荐的圆体字体（Varela Round / Nunito Sans）与 Things 方向不符，未采用，继续使用系统字体（中文 Noto Sans CJK）。
- Jetpack Compose 栈规则（UI UX Pro Max `--stack jetpack-compose`）：集中主题 token、不在组件里写死颜色、用 typography、动画用 animate*AsState / AnimatedVisibility、列表用 LazyColumn + 稳定 key。
- 原则：只改视觉层。功能、文案、数据、计数规则、五餐隔离、Room 4 结构都不动。

## 字体与层级
- 系统字体，不引入外部字体文件。
- 首页标题 28sp Black；页面标题 24sp ExtraBold；列表主文字 18–19sp Bold/Medium；正文 16sp；说明 13–15sp。
- 「x次」保持整段文字，不拆数字。

## 形状、间距、阴影
- 卡片圆角 16–20dp；按钮圆角 14dp（不再用胶囊 + 硬阴影）；图标底 44dp、圆角 12dp。
- 列表行最小高度 68–76dp，触控目标 ≥ 48dp。
- 页面左右边距 16dp，卡片间距 10dp。
- 无硬阴影（`hardShadow` 已改为空操作，保留签名以免改动布局）；卡片默认无边框、无投影；拖动中的卡片保留抬起投影。

## 关键页面规则
- **首页**：标题 + 图标在上；五餐为一列行，当前餐次整行浅强调底、文字加粗、右侧「现在」强调色；底部发丝线下一行：左「数据统计」、右「中文 ▾」，都是灰色文字按钮。
- **次页**：五个吃法统一为一列、同尺寸的横向卡片（图标底 + 名称 + 箭头），不混用宫格。
- **转盘**：扇区白 / 强调浅 / 暖黄浅三色轮换；外圈白色细边，无圆点；指针强调色；「帮我选」为强调色实心按钮、白字。
- **餐馆卡牌**：暖灰卡、无边框；Pick 为白底强调字按钮；卡背为浅赤陶格纹 + 「食」字章；「抽一家」强调色实心。
- **自己做**：分类块暖灰卡；「加入」类按钮白底灰描边，已加入为强调浅底 + 勾；底部操作栏白底。

## 交付前检查（UI UX Pro Max pro-rules 摘要）

- [ ] 窄屏 / 大字体 / 英文下不截断、可换行

## 动效（1.4.3 · Emil Kowalski 原则）
代码：`ui/Motion.kt`（曲线、时长、震动、按压、减少动态判断）。先按频率决定动不动：一天上百次的不动，几十次的只给轻反馈，偶尔的给标准过渡，很少发生的才留惊喜。

| 场景 | 频率 | 做法 |
|---|---|---|
| 所有按钮 | 常用 | 按下缩到 0.97，140ms 强缓出 |
| 可点的行 / 卡片 | 常用 | 按下缩到 0.98（分类标题 0.99） |
| Pick | 常用 | 无回弹；次数数字上翻 170ms |
| 首页 ↔ 吃法次页 | 常用 | 1.4.5 起原位淡入淡出，总计约 160ms；不横移，不改变离场页尺寸与边距 |
| 其他翻页 | 常用 | 前进：右侧 1/12 滑入 + 淡入 220ms；返回反向；顶部栏随所属页面一起过渡 |
| 分类展开 / 收起 | 偶尔 | 展开 220ms、收起 180ms，强缓出 |
| 加入购物车 / 菜单 | 偶尔 | 颜色与图标 150ms 渐变 |
| 购物车、烹饪菜单移动 | 偶尔 | 换分区时 260ms 缓入缓出滑到新位置 |
| 帮我选（转盘） | 每餐 | 起转即全速，2000ms 强缓出；过冲 ≤5° 后 260ms 回落；中心 0.9→1 脉冲 200ms；逐格轻震 + 落定确认震动；仍只转指针、停后不高亮 |
| 抽一家 | 每餐 | 收牌错开 30ms、洗牌、发牌错开 50ms（共 1130ms）；选中牌提起 120ms + 轻震；其余 200ms 淡出缩到 0.96；飞到中间翻面 460ms 缓入缓出；落定 180ms + 确认震动 |
| 本餐完成 | 很少 | 徽章 0.85→1、一圈扩散、对勾弹出、文字上浮 + 确认震动 |
| 语言切换、统计切餐、编辑弹窗 | — | 不加动画 |

规则：不用 ease-in；不从 scale(0) 出现；只动 transform 和 opacity（分类展开除外）；普通界面动效不超过 300ms，只有转盘和抽卡这两个「随机选」时刻更长；系统关闭动画时去掉位移和缩放，只保留淡入淡出。
